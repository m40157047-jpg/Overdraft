Политика конфиденциальности мобильного приложения «overdraft»Настоящая Политика конфиденциальности (далее — «Политика») разработана в соответствии с Федеральным законом РФ № 152-ФЗ «О персональных данных» и определяет порядок обработки и защиты информации при использовании мобильного приложения overdraft (далее — «Приложение»).
1. Основной принцип: Локальное хранение и шифрование
1.1. Приложение работает на основе локальной обработки данных. Разработчик не имеет удаленных серверов, не создает учетных записей пользователей и не собирает личную или финансовую информацию на внешних ресурсах.
1.2. Все данные, вносимые в Приложение, распознанные им или полученные из сервисных сообщений, хранятся исключительно в локальной базе данных на мобильном устройстве Пользователя.
1.3. Локальная база данных защищена с использованием стойкого алгоритма шифрования AES-256. Доступ к этим данным со стороны третьих лиц или разработчика технически невозможен.
2. Использование разрешений устройстваДля обеспечения полноценного функционала Приложение запрашивает доступ к следующим возможностям Android-устройства:
Доступ к SMS-сообщениям (READ_SMS / RECEIVE_SMS), в том числе в фоновом режиме: используется в автоматическом режиме для парсинга (распознавания) входящих сервисных уведомлений от банков о транзакциях, зачислениях и балансе. Фоновый режим необходим для того, чтобы Приложение могло автоматически фиксировать операции в момент получения SMS, даже когда экран устройства заблокирован или Приложение свернуто. Текст сообщений обрабатывается «на лету» строго внутри устройства, не сохраняется в открытом виде и никогда не передается по сети.Доступ к Интернету (INTERNET): используется исключительно для отправки точечных запросов к открытым источникам (например, API Центробанка или финансовых агрегаторов) с целью получения актуальных курсов валют. Приложение не передает через интернет финансовую историю или личные данные Пользователя.Доступ к микрофону / Запись аудио (RECORD_AUDIO): используется строго в момент активации Пользователем функции голосового ввода для распознавания категорий расходов и доходов голосом. Аудиопоток обрабатывается локально (или с помощью встроенных сервисов распознавания речи устройства), аудиофайлы не сохраняются и не передаются третьим лицам.Доступ к Камере (CAMERA): используется только для сканирования QR-кодов на кассовых чеках с целью автоматического добавления расходов. Приложение не выполняет скрытую съемку и не отправляет изображения во внешние сервисы.Использование биометрических данных (USE_BIOMETRIC / USE_FINGERPRINT): используется для аутентификации Пользователя при входе в Приложение (защита от несанкционированного доступа к финансовому менеджеру со стороны третьих лиц, имеющих физический доступ к телефону). Приложение использует стандартное системное API Android: сами биометрические данные (отпечатки пальцев, сканы лица) остаются в защищенном хранилище ОС, Приложение получает только ответ («успешно/неуспешно») и не имеет доступа к самим биометрическим шаблонам.Отправка уведомлений (POST_NOTIFICATIONS): используется для отображения системных push-уведомлений на экране устройства (например, напоминания о необходимости внести платеж, отчеты за день/неделю или подтверждение успешного фонового распознавания SMS).
3. Отсутствие скрытых трекеров3.1. Приложение не содержит встроенных маркетинговых, аналитических платформ (таких как Google Analytics, Firebase Analytics, Яндекс Метрика) или рекламных SDK, способных собирать скрытую статистику о действиях Пользователя или параметрах его устройства.
4. Права Пользователя и удаление информации
4.1. Пользователь имеет полный и единоличный контроль над всей информацией в Приложении.
4.2. Удаление всех данных, обработанных Приложением, осуществляется Пользователем самостоятельно в любой момент путем удаления Приложения с устройства либо через стандартное меню Android: Настройки -> Приложения -> overdraft -> Очистить хранилище/данные.
